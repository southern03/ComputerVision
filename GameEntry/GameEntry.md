# Storing Game Entries in an Array
### 1. 프로젝트 개요
C++의 클래스와 동적 메모리 관리, 객체지향 프로그래밍을 학습하기 위해 교재의 High Score 예제를 기반으로 구현한 프로그램이다. 사용자가 플레이어 이름과 점수를 입력하면 최고 점수 순위를 관리하며, 순위를 출력하거나 삭제할 수 있다.

### 2. 개발 환경
Language : C++

IDE : Visual Studio Code

Compiler : g++


### 3. 주요 기능
1. 플레이어 이름과 점수 입력

2. 동일 플레이어 중복 등록 방지

3. 동일 플레이어는 더 높은 점수만 반영

4. 최고 점수 순으로 자동 정렬

5. 최대 10개의 랭킹 유지

6. 특정 순위 삭제

7. 현재 랭킹 출력


### 4. 클래스 설계
GameEntry:

플레이어 이름 저장

플레이어 점수 저장

Getter 제공

Scores:

동적 배열을 이용한 랭킹 관리

점수 추가

점수 삭제

점수 출력


### 5. 구현 과정에서 배운 내용
(1) 동적 메모리 관리

entries = new GameEntry[maxEntries]; 를 통해 실행 중 필요한 크기의 배열 생성, 
delete[] entries; 를 통해 메모리를 해제

(2) 객체지향 프로그래밍

클래스를 이용하여 데이터와 기능을 하나의 객체로 관리하기

(3) const reference

void add(const GameEntry& e)를 사용하여 불필요한 객체 복사를 방지하고 원본 데이터 변경 막기

(4) 정렬 알고리즘

점수를 내림차순으로 유지하기 위해 Bubble Sort 방식으로 배열을 정렬

(5) 동적 배열 삭제

삭제 시 for(...) entries[j]=entries[j+1];를 통해 뒤 원소를 앞으로 이동시키는 방법 구현

(6) 중복 데이터 처리

동일 이름이 존재하면 낮은 점수는 무시, 높은 점수만 갱신하도록 구현

### 6. 구현 중 해결한 문제
switch 문의 case 내부에서 변수 선언으로 인해 발생한 컴파일 오류를 블록({})을 추가하여 해결

### 7. 개선 가능 사항
이 프로그램에서 최대 10개의 데이터만 저장할 수 있도록 배열 사이즈를 정의했다. 그래서 입력된 데이터의 상위 10개 데이터만 기록할 수 있는데 만약 모든 기록을 보관하고 싶다면 데이터의 개수가 10개를 초과할 경우 다른 더 큰 배열을 만들어 전부 데이터를 복사해야하는 불편함이 있다. 그래서 이를 해결하기 위해 연결 리스트를 사용할 수 있는데 연결 리스트를 사용하면 배열의 사이즈를 키우고 싶을 때 포인터를 이용해 논리적으로 데이터를 정렬할 수 있고 저장할 데이터의 개수도 좀더 유연하게 바꿀 수 있다.

### 8. 느낀 점
학교 강의자료의 예제 코드인 Storing Game Entries에 나머지 부분을 직접 구현 해보며 클래스 설계와 동적 메모리 관리, 객체지향 프로그래밍의 기본 개념을 실제 코드로 구현해 볼 수 있었다. 또한 단순히 기능을 구현하는 것뿐 아니라 데이터의 중복 처리, 정렬, 삭제, 출력 기능을 분리하면서 코드의 역할을 구분하는 중요성을 이해하였다.
